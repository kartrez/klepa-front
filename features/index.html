Возможности

Что умеет Клёпа

Агент для VS Code, который ведёт задачу целиком: разбирается в проекте, правит файлы, запускает команды и показывает, что сделал и сколько это стоило.

АгентПараллельная работаКонтрольКонтекст проектаПрямо в редактореРасширения

Режимы

Пишет и правит файлы, запускает команды. Режим по умолчанию.

Переключатель режима — под полем ввода, по кругу — Ctrl+.. Свои режимы создаются в настройках или ставятся из Marketplace.

Агент

Задачу ставите словами — Клёпа сама находит файлы, правит и проверяет.

Список дел по задаче

Большую задачу агент делит на шаги и отмечает выполненные прямо в заголовке задачи.

Уточняющие вопросы

Если данных не хватает, Клёпа показывает карточку с вариантами ответа вместо того, чтобы угадывать.

Подзадачи

Для поиска по проекту агент запускает отдельного помощника, чтобы не засорять основной контекст.

Параллельная работа

Несколько задач одновременно, каждая в своей копии репозитория.

Agent Manager

Панель со всеми сессиями агента: переключение, поиск, терминал и diff каждой задачи.

Кнопка Agent ManagerCtrl+Shift+M

Git worktree

Задача уходит в отдельный worktree, основная ветка остаётся нетронутой. Готовую сессию можно перенести в worktree.

«Новое Worktree» в Agent ManagerCtrl+N

Pull request из панели

Когда задача готова, PR открывается прямо из Agent Manager.

Ctrl+Shift+R

Обзор изменений

Все правки сессии собраны в одном diff: видно, что и где поменял агент.

Show Changes

Контроль

Агент ничего не делает втихую.

Снимки и откат

Перед правками сохраняется снимок. Любой шаг агента можно отменить и вернуть обратно.

Отмена в ленте задачи

Подтверждение команд

Команды терминала и запись файлов показываются перед выполнением — разрешаете или отклоняете.

Автоодобрение

Для доверенных действий подтверждение отключается одной кнопкой и так же включается обратно.

Ctrl+Alt+A

Стоимость на виду

В заголовке задачи — токены, заполненность контекста и цена, вверху панели — баланс и «Пополнить».

Контекст проекта

Клёпа работает с вашим проектом, а не с абстрактным кодом.

AGENTS.md и правила

Правила проекта из AGENTS.md подхватываются автоматически. Можно включить совместимость с CLAUDE.md.

Навыки и слэш-команды

Навыки добавляют агенту умений, а свои команды вызываются через «/» в поле ввода.

Reload Config and Skills

Память проекта

Клёпа запоминает важное о проекте между сессиями. Память можно посмотреть и выключить.

Show Project Memory

Индексация кода

Семантический поиск по репозиторию: агент находит нужное место по смыслу, а не только по имени.

Настройки → Индексация

Сжатие контекста

Длинная сессия сжимается в краткое резюме, чтобы не упираться в лимит модели.

Скриншоты и PDF

Картинку или PDF можно вставить прямо в запрос — например, макет или текст ошибки.

Прямо в редакторе

Не только чат: Клёпа встроена в привычные места VS Code.

Объяснить, исправить, улучшить

Выделите код — в контекстном меню и под лампочкой появятся действия Klepa AI.

Добавить в контекст

Выделенный фрагмент уходит в запрос одним сочетанием клавиш.

Ctrl+K Ctrl+A

Сообщение коммита

Кнопка в панели Git пишет сообщение коммита по вашим изменениям.

Generate Commit Message

Команда терминала

Опишите, что нужно, — Клёпа предложит команду. Упавшую команду можно объяснить или исправить.

Ctrl+Shift+G

Расширения

Подключайте инструменты, которых не хватает.

MCP-серверы

Базы данных, документация, трекеры задач и другие инструменты через протокол MCP.

Настройки → MCP

Marketplace

Готовые режимы, навыки и MCP-серверы ставятся в пару кликов.

Кнопка Marketplace

Автоматизация браузера бета

Агент открывает страницу, кликает и проверяет результат в браузере.

Включается в настройках

Генерация картинок бета

Иконки и иллюстрации для проекта прямо из чата.

Настройки → Экспериментальные

Где работает

Расширение из VS Code Marketplace, отдельный редактор ставить не нужно.

VS Codeверсия 1.105 и новее
Qoderвход через браузер поддержан

На macOS вместо Ctrl — Cmd. Возможности с меткой «бета» включаются в настройках плагина.
