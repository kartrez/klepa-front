Как установить Claude Code в России и Беларуси

Команды установки для Windows, macOS и Linux, требования и вход. И честно о главном: поставить программу можно, а войти и оплатить из России и Беларуси — нет.

Короткий ответ

Claude Code — консольный ИИ-агент Anthropic. Сама программа бесплатная и ставится одной командой. Но работать в ней можно только с платным аккаунтом Claude (Pro, Max, Team, Enterprise) или с ключом Anthropic Console. Бесплатный план claude.ai доступа к Claude Code не даёт.

Россия и Беларусь не входят в список стран, которые обслуживает Anthropic, — ни для claude.ai, ни для API. Поэтому после установки упираются во вход и оплату: аккаунт не зарегистрировать и не оплатить местной картой.

Требования

  • macOS 13 и новее, Windows 10 (1809) и новее, Ubuntu 20.04+, Debian 10+ или Alpine 3.19+.
  • 4 ГБ оперативной памяти, процессор x64 или ARM64.
  • Интернет и страна из списка поддерживаемых Anthropic.
  • Node.js нужен только для установки через npm — версии 22 и новее.

Команды установки

Команды взяты из официальной документации Anthropic. Откройте терминал и выполните одну из них.

macOS, Linux и WSL

curl -fsSL https://claude.ai/install.sh | bash

Рекомендованный способ. Программа обновляется сама в фоне.

Windows, PowerShell

irm https://claude.ai/install.ps1 | iex

Права администратора не нужны. Если стоит Git for Windows, агент будет выполнять команды через Git Bash.

Windows, командная строка CMD

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Homebrew на macOS

brew install --cask claude-code

Сама не обновляется: позже выполняйте brew upgrade claude-code.

WinGet на Windows

winget install Anthropic.ClaudeCode

Обновление — winget upgrade Anthropic.ClaudeCode.

npm

npm install -g @anthropic-ai/claude-code

Нужен Node.js 22 или новее. Не запускайте через sudo: это ведёт к ошибкам прав доступа.

Проверка: откройте новое окно терминала и выполните claude --version — команда должна напечатать номер версии. Подробную диагностику даёт claude doctor. Если установщик завершился ошибкой 403 или другой ошибкой curl, документация Anthropic советует поставить программу другим способом из списка.

Первый запуск и вход

  1. Перейдите в терминале в папку проекта.
  2. Выполните claude. Откроется браузер со входом в аккаунт Anthropic.
  3. Войдите в аккаунт с подпиской Pro, Max, Team или Enterprise либо подтвердите ключ Console, если задана переменная ANTHROPIC_API_KEY.
  4. Вернитесь в терминал и опишите задачу словами.

Что будет в России и Беларуси

Аккаунт

Регистрация на claude.ai и в Anthropic Console не рассчитана на пользователей из России и Беларуси: оба сервиса эти страны не обслуживают.

Оплата

Подписку Pro или Max и пополнение API оплачивают картой. Карты российских и белорусских банков Anthropic не принимает, МИР и БЕЛКАРТ — тоже.

VPN

VPN меняет адрес, но не страну аккаунта. Работа из неподдерживаемого региона нарушает условия Anthropic, и аккаунт могут заблокировать вместе с оплаченным периодом.

Способы оплаты и их риски разобраны в статье «Как оплатить Claude Code из России и Беларуси».

Список стран и условия Anthropic приведены по состоянию на октябрь 2026 года и могут измениться.

Модели Claude в VS Code без VPN

Если нужен ИИ-агент, который сам читает проект, правит файлы и запускает команды, его можно поставить из обычного каталога расширений VS Code. Klepa AI — такое расширение: внутри есть модели Claude, GPT, Gemini и другие, а вход и оплата работают из России и Беларуси.

  1. В VS Code откройте «Расширения», найдите «Klepa AI» и нажмите «Установить».
  2. Войдите через Telegram или Google — карта и VPN не нужны.
  3. Начните с бесплатной модели klepa/free, а для сложных задач выберите Claude.
  4. Опишите задачу словами: агент сам найдёт нужные файлы и покажет правки.

Это не копия Claude Code: Klepa работает в редакторе, а не в терминале, и у неё свои режимы Ask, Plan, Code и Debug. Подробное сравнение — на странице «Аналог Claude Code».

Частые вопросы

Можно ли скачать Claude Code бесплатно?

Да, программа бесплатная, установщик и пакет npm открыты. Но без платного аккаунта Claude (Pro, Max, Team, Enterprise) или ключа Anthropic Console работать в ней нельзя: бесплатный план claude.ai доступа к Claude Code не даёт.

Нужен ли Node.js для установки Claude Code?

Для рекомендованного установщика — нет: он ставит готовую программу. Node.js 22 и новее нужен только при установке через npm.

Почему Claude Code установился, но не получается войти?

Вход идёт через аккаунт Anthropic, а Россия и Беларусь не входят в список поддерживаемых стран. Установка от этого не зависит, вход и оплата — зависят.

Как проверить, что Claude Code установлен?

Откройте новое окно терминала и выполните claude --version — должен напечататься номер версии. Если терминал пишет, что команда не найдена, папка установки ещё не попала в PATH: помогает новое окно терминала или перезагрузка.

Как удалить Claude Code?

Зависит от способа установки: brew uninstall --cask claude-code, winget uninstall Anthropic.ClaudeCode или npm uninstall -g @anthropic-ai/claude-code. Нативную установку на macOS и Linux удаляют командами rm -f ~/.local/bin/claude и rm -rf ~/.local/share/claude.

Можно ли работать с моделями Claude без аккаунта Anthropic?

Да, через сервисы, которые подключают модели Claude у себя. В Klepa AI модели Claude доступны прямо в VS Code: вход через Telegram или Google, оплата в BYN картами МИР и БЕЛКАРТ, бесплатные модели на старте.
