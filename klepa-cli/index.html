Klepa CLI · Клёпа в терминале

Klepa CLI — AI-агент для кода в терминале

Та же Клёпа, что в VS Code, только в командной строке. Опишите задачу словами — агент разберётся в проекте, поправит файлы и запустит команды. Без VPN, оплата картами МИР и БЕЛКАРТ, аккаунт и баланс общие с плагином.

Установка на Linux, macOS и Windows

Подходит для Ubuntu и других 64-битных Linux на процессорах Intel или AMD, для Mac с Apple Silicon (M1 и новее) и для 64-битной Windows 10 и 11. Нужен только терминал, на Windows — PowerShell; права администратора не нужны.

  • Ubuntu и Linux64 бита, Intel или AMDДоступно
  • Windows10 и 11, 64 битаДоступно
  • macOSApple Silicon, M1 и новееДоступно
  1. 1

    Установите

    Выполните команду для своей системы. Клёпа встанет в ваш домашний каталог, права администратора не нужны.

    Linux и macOS — в терминале

    $curl -fsSL https://klepa.gpt-chat.by/install.sh | bash

    Windows — в PowerShell

    >irm https://klepa.gpt-chat.by/install.ps1 | iex

    Нужен PowerShell. В Windows 10 и 11 он уже есть: нажмите «Пуск» и наберите «PowerShell». В «Командной строке» (cmd) команда не сработает. Если PowerShell нет, установите его с сайта Microsoft.

  2. 2

    Войдите

    Откройте ссылку из терминала и войдите через Telegram или Google. Ключ сохранится сам, копировать его не нужно.

    $klepa login
  3. 3

    Запустите в проекте

    Перейдите в папку проекта и запустите Клёпу. Опишите задачу обычными словами.

    $cd ~/my-project
    $klepa

Установщик проверяет целостность архива и ставит Клёпу в ~/.local/bin/klepa, на Windows — в папку %LOCALAPPDATA%\Programs\Klepa. На Linux и macOS, если в текущем окне команда klepa ещё не находится, он покажет полный путь для входа, а в новых окнах терминала всё заработает само. На Windows команда работает сразу в том же окне PowerShell.

Полезные команды

  • klepaоткрыть Клёпу в текущей папке
  • klepa ~/projects/siteоткрыть Клёпу в другой папке
  • klepa -cпродолжить последний диалог
  • klepa run "обнови README"отправить задачу без интерфейса, например из скрипта
  • klepa modelsпоказать доступные модели
  • klepa --helpполная справка по командам

Плагин или CLI: что выбрать

Klepa CLI — если

  • привыкли работать в терминале и не хотите держать открытый редактор;
  • правите код на сервере по SSH, где нет графической среды;
  • хотите запускать задачи агенту из скриптов командой klepa run.

Плагин для VS Code — если

  • удобнее видеть правки прямо в файлах редактора;
  • нужны режимы Ask, Plan, Code и Debug в панели и генерация картинок.

Обновление и удаление

Чтобы обновить Klepa CLI, выполните команду установки ещё раз — она поставит свежую версию рядом и переключит на неё команду klepa.

Чтобы удалить на Linux и macOS, выполните:

$rm ~/.local/bin/klepa && rm -rf ~/.local/share/klepa-cli

На Windows — в PowerShell:

>Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Programs\Klepa"

Частые вопросы про Klepa CLI

Что такое Klepa CLI?

Это Клёпа для терминала. Агент запускается командой klepa в папке проекта, читает код, правит файлы и выполняет команды — так же, как плагин в VS Code, только без редактора.

На каких системах работает Klepa CLI?

На Ubuntu и других 64-битных Linux на процессорах Intel или AMD, на Mac с Apple Silicon (M1 и новее) и на 64-битной Windows 10 и 11. Mac на процессорах Intel и Windows на ARM пока не поддерживаются — на них работает плагин для VS Code.

Как установить Klepa CLI на Windows?

Нужен PowerShell — в Windows 10 и 11 он уже встроен: нажмите «Пуск» и наберите «PowerShell». Откройте его (не «Командную строку») и выполните irm https://klepa.gpt-chat.by/install.ps1 | iex. Клёпа встанет в папку пользователя без прав администратора, команда klepa заработает сразу в этом окне и в новых окнах.

Нужен ли VS Code для Klepa CLI?

Нет. CLI работает в любом терминале и не зависит от редактора. Поэтому его удобно запускать и на сервере по SSH.

Это аналог Claude Code?

По способу работы — да: агент живёт в терминале и сам ведёт задачу. Разница в доступе: Klepa работает из Беларуси и России без VPN, принимает МИР и БЕЛКАРТ и даёт выбрать модель — Claude, GPT, Gemini, Qwen, DeepSeek и другие.

Сколько стоит Klepa CLI?

Сама программа бесплатна. Оплата — как в плагине: за фактические запросы к платным моделям, без подписки, депозит от 5 BYN. Баланс общий для CLI и плагина.

Как войти, если терминал на сервере без браузера?

Выполните klepa login и откройте показанную ссылку в браузере на любом устройстве. После входа на сайте вернитесь в терминал — ключ сохранится сам. Ссылку не передавайте другим: она одноразовая и даёт вход в ваш аккаунт.
