Генерация изображений

Создавайте уникальные изображения по описанию прямо в VS Code и сохраняйте их в проект — без переключения между приложениями.

Klepa AI поддерживает генерацию изображений: визуальный контент для проекта можно создать, не выходя из редактора кода.

Настройка

Перейдите в настройки Клёпы и выберите модель генерации изображений.

  • Требуется вход через Telegram или Google
  • Выбор из нескольких современных моделей

Как это работает

Опишите, что вы хотите увидеть — Клёпа сгенерирует изображение и предложит сохранить его в папку проекта.

Удобство. Сгенерированные изображения сразу попадают в рабочую директорию, так что их можно использовать в коде без копирования.
