Marketplace Клёпы

Готовые инструменты от сообщества — MCP-серверы, специализированные режимы и навыки. Все бесплатно и подключаются в пару кликов.

Маркетплейс — это централизованный хаб с проверенными инструментами для разработки. Все они разделены на три категории: MCP, Modes (режимы) и Skills (навыки).

MCP (Model Context Protocol)

Интеграция с внешними данными и сервисами. MCP позволяет Клёпе взаимодействовать с файловой системой, базами данных, браузером и сторонними API напрямую.

Лучшие практики

  • Используйте MCP для актуального контекста (документация, логи)
  • Ограничивайте доступ только к необходимым директориям и API
  • Комбинируйте несколько MCP-серверов для сложных интеграций

Риски бездумного применения

  • Перегрузка контекстного окна лишними данными
  • Риск безопасности при доступе к чувствительным данным без контроля
  • Зависимость от стабильности внешних MCP-серверов

Modes (Режимы)

Специализированные роли для ИИ (Code Reviewer, Frontend Specialist и т.д.). У каждого режима свой системный промпт, настроенный на конкретный стиль работы.

Лучшие практики

  • «Frontend Specialist» для UI, «Code Reviewer» для проверки качества
  • Переключайтесь между режимами в зависимости от этапа разработки
  • Создавайте собственные режимы под специфику вашего проекта

Риски бездумного применения

  • Туннельное зрение — узкий режим может упустить общую картину
  • Слепое доверие советам «Code Reviewer» без знания бизнес-логики
  • Сложный режим для тривиальной задачи — overkill

Skills (Навыки)

Конкретные функциональные возможности — от обработки текста до интеграций с инструментами сборки.

Лучшие практики

  • Подключайте навыки, только когда базовая модель не справляется
  • Регулярно обновляйте навыки для новых фич
  • Тестируйте на небольших изолированных участках кода

Риски бездумного применения

  • Конфликты между навыками при одновременном использовании
  • Дублирование возможностей современных LLM
  • Падение производительности при большом количестве навыков

Популярные инструменты. В каждом разделе есть готовые наборы — Code Reviewer, Frontend Specialist, Test Engineer и многие другие. Подключаются одной кнопкой.
