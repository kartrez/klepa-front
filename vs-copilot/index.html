GitHub Copilot в Беларуси: работает ли и чем заменить

Официально нет: GitHub прямо называет Беларусь среди стран, куда Copilot нельзя продавать и экспортировать. Разбираем, что это значит, сколько стоит Copilot и чем его заменить в привычном VS Code без VPN.

Короткий ответ

GitHub Copilot — ИИ-помощник для кода от GitHub. Он подсказывает код при наборе, отвечает на вопросы по проекту, проверяет изменения и выполняет задачи в режиме агента.

В правилах GitHub об экспортном контроле сказано, что Copilot нельзя продавать, экспортировать и реэкспортировать в страны из особого списка. Сейчас в нём названы Куба, Иран, КНДР, Россия, Беларусь и часть регионов Украины. Местоположение пользователя GitHub определяет в том числе по IP-адресу и истории платежей.

Поэтому официального способа пользоваться Copilot из Беларуси нет. Обход через VPN и зарубежную карту остаётся на ваш страх и риск.

Цены — по таблице планов GitHub, в долларах в месяц. Запросы к чату и агенту GitHub считает в AI-кредитах: 1 кредит = 0,01 $. Дополнения кода на платных планах не ограничены.

Можно ли оплатить Copilot белорусской картой

По справке GitHub частные пользователи платят банковской картой или через PayPal, предоплаченные карты не принимаются. Но для Беларуси дело не в карте: продажа Copilot в страну запрещена правилами экспортного контроля, и ограничение сформулировано для Copilot целиком, без исключения для бесплатного плана.

Обходные пути — карта зарубежного банка, виртуальная карта или посредник — те же, что для Claude. Разбор с комиссиями и рисками — в статье «Как оплатить Claude Code из Беларуси».

Клёпа вместо Copilot

Клёпа — ИИ-агент для кода, который работает из Беларуси без VPN. Это расширение для VS Code, а для терминала есть Klepa CLI на Linux, macOS и Windows. Подход другой: Copilot вырос из автодополнения, а Клёпа получает задачу словами, сама открывает нужные файлы, правит код в нескольких местах и запускает команды.

  • Claude, GPT, Gemini, Qwen и DeepSeek — модель можно менять под задачу.
  • Оплата в BYN картами БЕЛКАРТ, Visa и Mastercard белорусских банков, а также МИР.
  • Подписки нет: пополнение от 5 BYN, деньги списываются за фактические запросы.
  • Бесплатные модели доступны после входа, с суточным лимитом сообщений.

Частые вопросы про Copilot в Беларуси

Работает ли GitHub Copilot в Беларуси?

Официально нет. В правилах об экспортном контроле GitHub пишет, что Copilot нельзя продавать, экспортировать и реэкспортировать в страны из особого списка, и Беларусь в нём названа вместе с Россией, Кубой, Ираном и КНДР. Местоположение GitHub определяет в том числе по IP-адресу и истории платежей. Обход через VPN и зарубежную карту остаётся на ваш риск.

Можно ли оплатить GitHub Copilot белорусской картой?

GitHub принимает банковские карты и PayPal, предоплаченные карты не принимает. Но для Беларуси вопрос не в карте: продажа Copilot в страну запрещена правилами экспортного контроля. Официального способа оплатить Copilot из Беларуси нет. В Клёпе оплата идёт в BYN картами белорусских банков.

Есть ли бесплатный Copilot?

Есть план Free: 2 000 дополнений кода в месяц и ограниченные чат и агент, карта не нужна. Проверенные студенты получают бесплатный план Student. Но ограничение GitHub для Беларуси сформулировано для Copilot целиком, без исключения для бесплатного плана. В Клёпе бесплатные модели доступны после входа без VPN, с суточным лимитом сообщений.

Сколько стоит Copilot в 2026 году?

Pro — 10 $ в месяц, Pro+ — 39 $, Max — 100 $. Для компаний Business стоит 19 $ за место, Enterprise — 39 $. Запросы к чату и агенту считаются в AI-кредитах (1 кредит = 0,01 $): в Pro их 1 500 в месяц, в Pro+ — 7 000, в Max — 20 000. Дополнения кода на платных планах не ограничены.

Клёпа заменяет автодополнение Copilot?

Не полностью. Copilot силён подсказками в момент набора текста. Клёпа решает задачу иначе: вы формулируете, что нужно сделать, и агент вносит правки целиком. Для многофайловых изменений и рефакторинга агентный подход удобнее, для набора кода строка за строкой — автодополнение.

Нужен ли VPN для Клёпы?

Нет. Клёпа рассчитана на пользователей из Беларуси: вход через Telegram или Google, оплата в BYN, запросы к моделям идут через доступную отсюда инфраструктуру.
